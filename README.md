
# LLM Prompt Pipeline & JSON Extractor

## Project Overview
A beginner-friendly Python project that extracts structured resume information using Generative AI.

## Technologies Used
- Python 3
- Google Gemini API
- Pydantic
- JSON

## Features
- Extract candidate name and email
- Identify skills and education
- Validate structured data
- Return results in JSON format

## Project Files
- main.py: Main Python program
- requirements.txt: Required Python libraries
- README.md: Project documentation

## Installation
Install the dependencies:

pip install -r requirements.txt

## Configuration
Set your GEMINI_API_KEY environment variable securely.

## Run
python main.py

## Learning Outcomes
- Prompt engineering
- API integration
- JSON extraction
- Data validation
